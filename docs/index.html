Patterns

Static keys are everywhere, OAuth is close behind

81 apps accept an API key or token and 68 accept OAuth2. 53 take both, so build on a key and ship on OAuth. Only 10 are OAuth-only.

The second gate is the hidden cost

27 self-serve apps still require app review, a partner program or a security review for customer accounts. 10 more could not be settled. Productivity apps show none of this; ads and social have the most.

Sales calls are the top hard blocker

Of the 23 apps not ready today, 8 sit behind sales or a partnership, 6 behind a paid plan, 4 behind vendor approval, 3 have a narrow API and 2 only run locally.

An official MCP server no longer sets an app apart

86 vendors publish one that acts on the product. 15 of those still sit on apps we cannot freely build for, so an MCP server is not proof of access. Docs-search servers do not count here.

The agent

  1. Crawl

    Python script reads each hint URL and five likely links, then applies rules. This is pass 0.

  2. Research

    Ten agents, one per category, search and read vendor docs, then fill a strict schema with a quote per claim.

  3. Check quotes

    Script reloads every cited page. Failures become work for the next step.

  4. Attack

    Ten fresh agents on a stronger model try to refute each record. Gold labels were moved out of reach.

  5. Reconcile

    Score, cross-check with Composio's catalogue, settle disputes in a browser, log every override.

What went wrong

  • Some apps beat the agent. Paygent Connect has no public docs and its identity is a best guess. iPayX, Sentry and Aircall access answers are below 60% confidence.
  • One gold label was wrong. Pinterest's MCP server was marked live from a search summary; the vendor page says it has not launched.
  • fanbasis now redirects to Commas. Its docs domain is not linked from the vendor site, so that verdict needs a human check.
  • Paygent's site hides instructions aimed at AI summarizers. The agents treated them as data and ignored them.
  • Two verifiers tried several browser identities on Meta's docs after an error. The safety check blocked it, they stopped, and the Meta pages were read in a normal browser instead.
  • Vendor pages contradict each other for MrScraper, Clay, Aircall and Squarespace. The table shows the more specific page and lists the conflict in the data file.
  • Composio's SDK and MCP were not used to run this. Its public catalogue served as a second source.
